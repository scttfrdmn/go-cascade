# Seeded dangerous-mode test — 2026-07-25

The definitive test of the §3.1 dangerous mode for this judge. Every prior run
depended on the models emitting a wrong candidate; here wrong candidates are
**seeded deliberately** via `KilledMutants` — mutants of a sampled solution that
compile and are killed by the hidden tests, so each is provably wrong by
execution. Every such candidate is judged at strict / balanced / permissive.
Because the candidate is known-wrong, **every judge PASS is an unambiguous false
acceptance (η_fa)**. 6 problems, 17 killed mutants, α=0.10, zero errors, no
problem lacked a wrong candidate.

## Result

| strictness | judged | false-accept | η_fa rate |
|------------|--------|--------------|-----------|
| strict     | 17     | 0            | 0.000     |
| balanced   | 17     | 0            | 0.000     |
| permissive | 17     | 0            | 0.000     |

## Finding: the danger did not appear — the judge caught every seeded defect

Presented with 17 provably-wrong programs — each a single operator swap,
increment flip, or condition negation away from a correct solution — the judge
returned FAIL on all 17, at every strictness level, **including permissive**
("when in doubt, PASS"). η_fa = 0 throughout.

This is the cleanest result of the study because it removes every confound the
earlier sweeps had:

- The candidates are provably wrong (execution killed them), not "probably
  wrong". No reliance on the models producing a defect.
- The judge saw all 17 at each level, so the sample is fixed across strictness.
- The one η_fa signal earlier runs saw (the `seq_longest_run` `>=`-for-`>` in the
  confounded sweep) is exactly the mutation class harvested here — and the judge
  caught it this time.

Interpretation, stated carefully:

- **For this judge (Claude Sonnet 4.6) and this defect class (single-edit
  mutation defects in short stdlib Go), the §3.1 dangerous mode is not
  reachable by the strictness prompt.** The judge reads these off-by-one and
  operator-swap bugs reliably, and loosening the tie-break does not make it pass
  them, because it is not *in doubt* about them — it identifies them.
- Strictness did not move η_fa here (it stayed 0) because η_fa had no headroom:
  the judge was already correct on every candidate. Strictness moves only cases
  the judge is uncertain about, and it was certain (and right) on all 17.

## What this does NOT establish

- **It does not prove judges are safe in general.** The one confirmed live η_fa
  in the whole study was a **data race** (`conc_parallel_map`, paired pilot #8) —
  a defect class the mutation operators here do not produce and a reader
  genuinely cannot see. The seeded test covers single-edit *logic* mutations, not
  concurrency or specification-misreading defects. A seeded test over *race*
  mutations (or LLM-authored subtly-wrong solutions that read as clean) could
  still exhibit η_fa; this experiment does not touch that.
- **n is small** (17 candidates, 6 problems). A zero here is consistent with a
  small-but-nonzero true η_fa on this defect class.

## Where the whole study lands

Across five live experiments:

| run | what it isolated | η_fa result |
|-----|------------------|-------------|
| paired pilot #8 | oracle (shared stream) | η_fa=3 — a **data race** the judge missed |
| hard tier #9 | reader-invisible defects | η_fa=0 (judge over-rejected instead) |
| controlled sweep #11 | strictness (shared stream) | η_fa untestable (all candidates correct) |
| seeded test (this) | strictness on **known-wrong** logic defects | η_fa=0 at every level |

The consistent, defensible conclusions:

1. **Execution is sound in every run** (realized == empirical, β=0). Demonstrated
   live, repeatedly.
2. **The judge's one demonstrated blind spot is concurrency** — the race it
   passed is the only confirmed live false acceptance, and it is exactly the
   defect class a reader cannot verify.
3. **For single-edit logic defects, this judge is reliable and strictness-robust**
   — it catches them regardless of the tie-break.

So the §3.1 danger is real but **narrow** for a strong modern judge: it lives in
the defects reading cannot cover (races, and by extension aliasing / spec
misreads), not in ordinary logic bugs. That is a more precise claim than the
paper's general framing, and it is the executable oracle's clearest value —
covering exactly the blind spot the judge has.
